Published research

  1. 2024

    IEEE DRCN 2024, Montreal

    On the Impact of the RPL Decreased Rank Attack on 6TiSCH Networks

    Studied how the RPL decreased rank attack disrupts 6TiSCH networks, which run on the TSCH mode of IEEE 802.15.4-2015 and use RPL for multi-hop IPv6 routing. Implemented on Contiki-NG in C, with Python and Bash scripting.

    M. Mahyoub, S. Hossain and A. Matrawy. Carleton University, Next Generation Networks Lab.

  2. 2019

    IEEE TENCON 2019, Kochi

    Application of Machine Learning in Credit Risk Assessment: A Prelude to Smart Banking

    A machine learning system that predicts whether a person can repay a loan, which helps lenders decide whether to approve it.

    S. Z. H. Shoumo, M. I. M. Dhruba, S. Hossain, N. H. Ghani, H. Arif and S. Islam.

  3. 2019

    ICREST 2019, Dhaka

    IoT Based Patient Monitoring System Using ECG Sensor

    Continuously monitors a patient's condition and saves the readings to a cloud server for remote viewing, with an emergency push button and an on-request live camera stream.
